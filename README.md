## Stack

- **Framework:** Astro 5 + TypeScript
- **Styling:** Tailwind CSS 4 + CSS custom properties (design tokens)
- **Runtime:** Cloudflare Workers (`@astrojs/cloudflare`)
- **Hosting:** Cloudflare (edge)
- **Content:** Astro Content Collections (MDX)
- **CI/CD:** GitHub Actions + Cloudflare Git integration
- **Fonts:** Inter Display · Inter · JetBrains Mono (self-hosted)

## Local Development

```bash
npm install
npm run dev          # http://localhost:4321
npm run build        # production build to dist/
npm run preview      # preview the build
npm run check        # TypeScript + Astro check
npm run lint         # ESLint
npm run format       # Prettier
```
